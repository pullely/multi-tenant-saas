# sdk

Runtime-agnostic TypeScript SDK for the Multi Tenant Saas control plane API

A shared package of the multi-tenant-saas workspace, consumed by the components
below at build time.

## Depended on by

- **cli** — First-class TypeScript CLI for the Multi Tenant Saas control plane API
- **web-console-next** — Next.js 15 + opennextjs/cloudflare delivery of the Multi Tenant Saas web console (per-environment, Workers + Static Assets)
